Privacy Policy — anago-uploader

Last updated: 2026-11-08

What this app is

anago-uploader is a personal automation tool operated by the owner of the YouTube channel "anago" (@anago-i5k). It uploads videos to that single channel using the YouTube Data API v3 (scope: youtube.upload only).

Data we access

  • The app accesses only the channel owner's own Google account, with the youtube.upload scope, solely to upload videos to the owner's channel.
  • The app does not access, collect, store, or share any other user's data.
  • No personal data is sold, rented, or disclosed to third parties.

Data storage

  • OAuth credentials (client ID, client secret, refresh token) are stored only in the owner's private infrastructure (local secure storage and GitHub Actions Secrets for the owner's private repository) and are used exclusively to authenticate uploads.
  • Uploaded video files and metadata originate from the owner's own content management system.

Revoking access

The owner can revoke the app's access at any time from the Google Account permissions page (https://myaccount.google.com/permissions).
