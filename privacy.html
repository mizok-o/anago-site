Privacy Policy — anago-uploader

Last updated: 2026-11-14

What this app is

anago-uploader is a personal automation tool operated by the owner of the YouTube channel "anago" (@anago-i5k). It uploads videos to that single channel using the YouTube Data API v3 (scope: youtube.upload only).

Data we access

  • The app accesses only the channel owner's own Google account, with the youtube.upload scope, solely to upload videos to the owner's channel.
  • The app does not access, collect, store, or share any other user's data.
  • No personal data is sold, rented, or disclosed to third parties.

Data storage

  • OAuth credentials (client ID, client secret, refresh token) are stored only in the owner's private infrastructure (local secure storage and GitHub Actions Secrets for the owner's private repository) and are used exclusively to authenticate uploads.
  • Uploaded video files and metadata originate from the owner's own content management system.

How we use the data

  • The youtube.upload scope is used only to upload videos made from the owner's own articles to the owner's own channel. No other Google user data is read.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Google user data is not used for advertising, is not sold to data brokers or information resellers, is not used to determine credit-worthiness or for lending purposes, and is not used to develop, improve, or train generalized or non-personalized AI or machine-learning models.

Sharing

Google user data is not shared with, transferred to, or disclosed to any third party.

Security

Credentials are stored encrypted in GitHub Actions Secrets and are never written to logs or source code. All communication with Google APIs uses HTTPS (TLS encryption). Access is limited to the owner.

Retention and deletion

  • The refresh token is kept only while the app is in use. When the app is no longer used, it is deleted from GitHub Actions Secrets and access is revoked.
  • Temporary video files created during processing are deleted when each run finishes.
  • To request deletion of any data, contact the address below.

Revoking access

The owner can revoke the app's access at any time from the Google Account permissions page (https://myaccount.google.com/permissions).
