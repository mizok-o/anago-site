anago-uploader

anago-uploader is a personal automation tool for the YouTube channel "anago" (https://www.youtube.com/@anago-i5k).

It turns the channel owner's own written articles into short vertical videos and uploads them to the channel via the YouTube Data API v3. It is used only by the channel owner, only with the youtube.upload scope, and does not collect or process any third-party user data.
